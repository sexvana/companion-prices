# AI companion public pricing snapshot

Cited, machine-readable snapshots of **public prices, free-tier limits and account rules** for AI companion products.

Canonical human-readable reviews: **https://sexvana.com**

This repository is a citable mirror. Every number comes from the vendor\'s own public page. A missing figure is a figure the vendor does not publish, not a zero.

No affiliate links. No tracking parameters. Source URLs point at the vendor.

## Files

| File | What it is |
| --- | --- |
| `facts.csv` | One row per cited fact. Columns: `product`, `fact`, `value`, `numeric`, `unit`, `source_url`, `retrieved_at`. |
| `facts.json` | The same rows as JSON. |

`retrieved_at` is the date that row was read, not a promise the vendor has not changed it since.

## Methodology

- Harvest only from a vendor\'s public page. No login-walled tables, no blogs, no estimates.
- Where the vendor publishes nothing, the row says so rather than inventing a number.
- Adult products; this dataset is text facts only. It does not host media.
